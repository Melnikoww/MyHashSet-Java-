# MyHashSet

Реализация множества на хеш-таблице. Класс `MyHashSet<T>` хранит элементы в массиве корзин `Object[]`, каждая корзина — цепочка узлов `Entry<T>` (разрешение коллизий методом цепочек). Стартовая вместимость — 16, при заполнении 75% ячеек (`LOAD_FACTOR = 0.75`) таблица расширяется вдвое, и все элементы пересчитываются заново по новой длине массива.

Интерфейс `HashSetMethods` задаёт операции множества. Консольное приложение `App` вызывает их по меню.

## Методы

| Метод | Что делает |
|---|---|
| `add(value)` | Добавляет элемент. Возвращает `true`, если элемента ещё не было, `false` для дубликата |
| `remove(value)` | Удаляет элемент. Возвращает `true`, если он был найден и удалён |
| `contains(value)` | Проверяет наличие элемента во множестве |
| `getSize()` | Число элементов |
| `isEmpty()` | `true`, если во множестве нет элементов |
| `clear()` | Очищает множество и сбрасывает вместимость до начальной |
| `toArray()` | Возвращает все элементы в виде `Object[]` |

## Как устроено внутри

- Позиция элемента вычисляется как `Math.abs(value.hashCode() % capacity)` — по этой формуле элемент попадает в одну из корзин.
- Если два элемента попадают в одну корзину, они выстраиваются в цепочку через поле `next` узла `Entry`.
- Внутренние массивы имеют тип `Object[]`, а при чтении из них выполняется приведение к `Entry<T>` (аннотации `@SuppressWarnings("unchecked")` глушат предупреждения компилятора о стирании типов).
- Ресайз запускается в `add` **до** вставки нового элемента: как только `size` достигает 12 (`16 * 0.75`), массив расширяется до 32 ячеек, и все элементы перераспределяются заново.

Множество не хранит порядок элементов: вывод `toArray()` зависит от хешей и последовательности вставок. Проверять содержимое в тестах нужно без учёта порядка — например, через `contains` или сравнение с `HashSet`.

## Сборка и тесты

Команды запускаются из каталога `myhashset`. Нужны JDK 8+ и Maven.

```bash
cd myhashset
mvn test
```

Собрать классы без тестов:

```bash
mvn -DskipTests compile
```

## Консольная проверка

```bash
cd myhashset
mvn -DskipTests compile
java -cp target/classes com.myhashset.App
```

После каждой команды программа печатает содержимое множества, если оно изменилось.

| Команда | Действие |
|---|---|
| 1 | `add` — добавление элемента |
| 2 | `remove` — удаление элемента |
| 3 | `getSize` — текущий размер множества |
| 4 | `contains` — проверка наличия элемента |
| 5 | `clear` — очистка множества |
| 6 | Показать всё текущее множество |
| 7 | `isEmpty` — проверка на пустоту |
| 0 | Выход |
